De deuren van Wonderland

🗝 Jouw geheime code

Typ de code die je van je docent hebt gekregen. Laat hem aan niemand zien.

Wie ben jij in Wonderland?

Kies een avatarnaam. De anderen zien alleen deze naam, op de kaart op het bord. Wie erachter zit, weet alleen je docent.

Kies een naam die je ook op het bord durft te laten zien.
Kies een hoofdstuk. Je docent zet een nieuw hoofdstuk open als de les begint.
